This is a solved example of an ERP learning assignment. It also works as a framework for processing EEG signal windows.


I wrote it for teaching an undergraduate class, it loads data from the EEGBCI dataset (Goldberger et al. 2000) through the MNE package (as shown in the documentation file for datasets: https://mne.tools/stable/documentation/datasets.html).


The signal processing is original code.



References:
Ary L. Goldberger, Luis A. N. Amaral, Leon Glass, Jeffrey M. Hausdorff, Plamen Ch. Ivanov, Roger G. Mark, Joseph E. Mietus, George B. Moody, Chung-Kang Peng, and H. Eugene Stanley. PhysioBank, PhysioToolkit, and PhysioNet: Components of a new research resource for complex physiologic signals. Circulation, 2000. doi:10.1161/01.CIR.101.23.e215.
